Smart Attendance

An IoT-based attendance system designed to make attendance recording faster, easier and more organized using RFID technology.

ESP32 RFID LCD IoT Embedded C/C++
01

🧠 What is Smart Attendance System?

Smart Attendance System is an IoT-based project that uses RFID technology to identify users and demonstrate an automated attendance process.

Instead of manually writing attendance, an RFID card or tag can be scanned and the system processes the identification automatically.

02

⚙️ How Does It Work?

01

RFID Card

The student or user has an RFID card/tag.

02

Scanning

The card is placed near the RFID reader.

03

Processing

The microcontroller reads and processes the RFID information.

04

Confirmation

LCD, buzzer and LEDs can provide attendance/status feedback.

03

❗ Problem

Traditional attendance systems can require manual entry, which takes time and can result in human errors.

Managing attendance records manually can also become difficult when the number of students or employees increases.

04

💡 Solution

The project demonstrates how RFID technology can automate the identification process.

A user can scan an RFID card and the system can identify the card and provide immediate feedback through the connected components.
