🧠 What is Eru AI?

Eru AI is a personal AI assistant project developed using Python. The project is designed to allow users to interact with an intelligent desktop assistant through text and voice.

The main goal of Eru AI is to create a more natural and interactive way of communicating with a computer.

02

⚙️ How Does It Work?

04

Assistant Response

Eru displays the response and can provide a voice reply.

03

❗ Problem

Using a computer often requires users to manually open applications, search for information and perform repetitive actions.

This project explores how an AI assistant can provide a centralized interface for interacting with a computer more naturally.

04

💡 Solution

Eru AI provides an interactive assistant interface where the user can communicate with the system using text or voice.

The assistant processes the request, generates an appropriate response and presents the result through its interface.
